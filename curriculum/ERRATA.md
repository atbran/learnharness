# Curriculum errata (fix in the course JSON)

Errors found by the quick-check authors while writing questions. The lesson-split pass applies them.
Delete each entry once it's fixed.

- **p6-l038 (helium variational):** the key equation ⟨H⟩ = (2Z² − 27Z/4)E₁ has the wrong sign. With E₁ = −13.6 eV it should read
  ⟨H⟩ = (−2Z² + 27Z/4)E₁, which gives −77.49 eV at Z = 27/16.
- **p6-l040 (quantum bouncer, WKB):** one hard wall means the quantization condition is (n − 1/4)πħ, not (n − 1/2)πħ.
  Keep (n − 1/2) only for smooth two-turning-point wells such as the oscillator.
- **s3-l012 (LIGO):** the objective says δL ≈ 4×10⁻¹⁹ m for 4 km arms at h = 10⁻²¹. It should be δL = hL/2 = 2×10⁻¹⁸ m.
- **s3-l009 (Hawking temperature):** the objective says ≈ 60 nK for a solar mass; the computed value is 61.7 nK. Write "≈ 62 nK".
- **m2-l003 / m2-l012 (spherical coordinates):** the keyEquations use the math convention (φ polar) while the lessons use the physics
  convention (θ polar, φ azimuth). Make the keyEquations use the physics convention throughout.
